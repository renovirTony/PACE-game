# 📡 PACE 通訊先鋒 (PACE: Comms Protocol)

> **戰術應急通訊網頁桌遊 · 現代防災與軍規通訊架構模擬**  
> 融合真實 **PACE (Primary, Alternate, Contingency, Emergency)** 通訊備援規劃準則，考驗指揮官在極端災害與電磁干擾環境下的應變決策！

---

## 🎮 遊戲核心概念 (Game Concept)

**PACE 原則** 是美軍與各國災害防救組織的核心準則：
*   **[P] Primary (主要通訊)**：日常最高頻寬、最便捷之主要通訊管道（例如：5G 行動專網、低軌衛星 Starlink、微波中繼塔）。
*   **[A] Alternate (備用通訊)**：主要手段受阻時的標準替代方案（例如：VHF/UHF 戰術跳頻無線電、短波電離層反射電台、LoRa 網狀自癒節點）。
*   **[C] Contingency (應急通訊)**：惡劣天候、地底或斷電環境下的強韌手段（例如：野戰手搖有線電話 TA-312、地底震動聲學儀、信差無人機）。
*   **[E] Emergency (緊急通訊)**：全防線崩潰時的終極保命手段（例如：阿爾迪斯高亮度摩斯信號燈、日光反射鏡、摩托車偵搜信差、軍用信鴿）。

---

## 🕹️ 遊戲玩法特色 (Key Features)

1.  **智慧 Fallback 備援連通演算法**：
    *   發起危機任務通訊時，系統會智慧依序檢驗 `[P] ➔ [A] ➔ [C] ➔ [E]` 槽位。
    *   若遇電磁風暴或基地台斷電，主要手段自動跳過並切換至備援，成功觸發應急/緊急手段可獲得高額應變積分！
2.  **動態突發危機與全域天候事件**：
    *   包含：雪崩搜救、地下坑道崩塌、高空電磁脈衝爆震 (EMP)、超強颱風、全區電網大停電、全頻段白雜訊干擾。
3.  **多樣化遊戲模式與 AI 對手**：
    *   **單人戰役 vs 智慧 AI**：支援 1~3 位不同戰術風格的 AI 對手（防守強韌型、積極進攻型、平衡型）。
    *   **本地多人 (Pass & Play)**：支援 2 名指揮官同機輪流作戰。
4.  **豐富裝備庫與戰術卡牌**：
    *   超過 40+ 種具備軍事與實務真實背景的通訊卡牌。
    *   戰術支援卡牌：柴油發電機充能、八木天線校準、先遣無人機偵察、法拉第籠抗 EMP 裝甲。
5.  **沉浸式戰術指揮 HUD 與原生合成音效**：
    *   採用 Web Audio API 實現電台靜電雜音、摩斯密碼、戰術蜂鳴、通訊成功 Roger Beep 等音效，無外部檔案相依。
    *   科幻戰術螢幕與作戰日誌即時監聽。
6.  **內建 PACE 原理百科與互動規則手冊**：
    *   寓教於樂，讓玩家在遊玩中深入了解真實應急通訊架構規劃。

## 🚀 快速開始 (Quick Start)

### 1. 安裝相依套件
```bash
npm install
```

### 2. 本地啟動開發伺服器
```bash
npm run dev
```
瀏覽器打開 `http://localhost:3000` 即可暢玩！

### 3. 編譯正式版本
```bash
npm run build
```
編譯產物將輸出至 `dist/` 目錄。
